## 걸림돌 & 해결 (다음 사람을 위해)

1. **에이전트 인증 확인 15초 타임아웃(SPEC-01 계획값)은 비현실** — 이 PC 실측 콜드 스타트 46초.
   → settings `agent_auth_timeout_sec` 기본 60초로 조정됨. 첫 실행 전 마법사에서 한 번
   워밍업해 두면 실행이 빨라진다.
2. **CLI 가 stdin 을 3초 기다리는 문제** → 어댑터가 `stdin=DEVNULL` 로 실행하도록 수정됨.
3. **에이전트 실행 시간**: 인증 43s + 제안 ~5분 (simulate 8회 스윕 포함). 타임아웃은
   설정에서 900s 로 여유 있게 (기본 600s).
4. 포트 8100 은 운영 서버 팀(Docker)이 사용 중 — mock 은 8101 (README 참고).
5. **(리뷰에서 발견) npm `.cmd` 셔틀로 설치된 claude/codex 는 여러 줄 argv 프롬프트가
   첫 줄에서 잘리고 한글이 깨진다** (cmd.exe `%*` 재전개) — MISSION 은 이제 stdin 파이프로
   전달한다 (`type MISSION.md | claude -p ...` 와 등가). 이 PC 는 네이티브 claude.EXE 라
   운 좋게 통과했었음 — 다른 PC 에서도 이제 동일하게 동작한다.
