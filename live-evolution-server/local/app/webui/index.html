처음이세요? — 이 콘솔의 사용 순서 (진화 1세대의 전 과정)
이 콘솔의 목적은 하나입니다: 정답지(사람이 실시간으로 만든 라벨)로 판정 엔진의 약점을 찾아, AI 에이전트가 제안한 개선안을 시험하고, 통과한 것만 사람이 [채택]하는 것. 아래 순서대로 한 바퀴 돌면 "진화 1세대"가 완성됩니다.
에이전트 연결
Claude Code 또는 Codex 를 연결합니다. 개선안을 "생각해 주는" 도구 — 한 번 초록불이 되면 이후에는 신경 쓸 일이 없습니다.
 검증 세션으로 정답지 만들기
피검자에게 "집중해!"·"멍때려~" 지시하며 동시에 버튼을 눌러 5분짜리 정답지를 만듭니다. 10개 이상 모여야 진화를 실행할 수 있어요. (기기 = 웹캠 프로토 필요)
 오답노트 확인
정답지와 기계 판정이 어긋난 구간을 봅니다 — "지금 엔진이 뭘 못 맞히나"가 한눈에. 여기서 바로 [진화 실행]으로 넘어갑니다.
 진화 실행 → 제안 검토 → 후보 등록
AI 가 오답 증거를 보고 파라미터 개선안을 만들어 옵니다(수 분 소요). 변경 내용과 근거를 읽고 [후보 등록]을 누르면 자동으로 시험(evaluate)까지 진행됩니다.
 성적표 검토 → [채택]
숨겨둔 시험지(holdout) 성적을 보고 사람이 결정합니다. [채택]을 누르기 전에는 아무것도 운영에 반영되지 않습니다.
 세대 이력에서 확인 (필요시 롤백)
채택/기각의 전 과정이 계보로 남습니다. 문제가 보이면 [롤백] 두 번 클릭으로 직전 기준으로 되돌립니다.

메뉴 한 줄 요약

  • 검증 세션 — 정답지 생산 (매일 쓰는 화면)
  • 아카이브 — 모든 검증 세션의 열람·연구 제외/복원 (삭제는 없음)
  • 오답노트 — 현재 엔진의 약점 지도
  • 진화 실행 — AI 제안 1세대를 돌리는 곳
  • 성적표 — 채택 버튼이 있는 유일한 곳
  • 세대 이력 — 계보·원문·인쇄(임상 문서)·롤백
  • 에이전트 / 설정 — 최초 1회 + 가끔
연결 카드 3장 읽는 법
  • ⓐ 운영 서버 — 세션·정답지·채점의 원천. 빨간불이면 mock 을 켜세요: python run_mock_ops.py --port 8101 (실서버 S5 완성 전까지의 대역). 이 콘솔은 원천 데이터를 갖지 않아서, 여기가 꺼져 있으면 화면들이 "연결 안내"만 보여줍니다.
  • ⓑ AI 에이전트 — 하나만 초록이어도 진화 실행이 가능합니다. 미연결이면 [연결 마법사]로.
  • ⓒ 데이터 현황 — 정답지 10개가 진화 실행의 최소 조건. train : holdout 은 자동 분할이며 손댈 수 없습니다(시험 공정성).
