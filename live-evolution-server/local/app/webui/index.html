First time? — how to use this console (the full path of one evolution generation)
This console has one purpose: use ground truth (labels a human makes in real time) to find the decision engine's weaknesses, test the improvements an AI agent proposes, and let a human [Adopt] only the ones that pass. Going around the steps below once completes "one evolution generation".
Connect an agent
Connect Claude Code or Codex. The tool that "thinks up" improvements — once it turns green you never have to touch it again.
 Make ground truth in a validation session
Instruct the subject "focus!" / "zone out~" while pressing the button at the same time to make a 5-minute ground truth. You need 10 or more before you can run evolution. (device = webcam proto required)
 Check the Mistake Log
See the bins where ground truth and the machine's judgment disagree — "what the engine gets wrong right now" at a glance. Jump straight to [Run evolution] from here.
 Run evolution → review proposal → register candidate
The AI reads the mistake evidence and comes back with a parameter improvement (takes a few minutes). Read the changes and rationale, press [Register candidate], and it proceeds automatically to the exam (evaluate).
 Review the gate report → [Adopt]
A human decides after seeing the hidden exam (holdout) score. Nothing reaches operations until you press [Adopt].
 Check in the generation history (rollback if needed)
The whole adopt/reject path is kept as lineage. If you spot a problem, [Rollback] with two clicks reverts to the previous criteria.

One-line menu guide

  • Validation session — produce ground truth (the daily-use screen)
  • Archive — browse all validation sessions, exclude/restore from research (no deletion)
  • Mistake Log — a map of the current engine's weaknesses
  • Run evolution — where you run one generation of AI proposals
  • Gate report — the only place with the Adopt button
  • Generations — lineage, raw transcripts, print (clinical document), rollback
  • Agent / Settings — once at first + occasionally
How to read the 3 connection cards
  • ⓐ Operations server — the source of sessions, ground truth, and scoring. If red, start the mock: python run_mock_ops.py --port 8101 (a stand-in until the real server S5 is done). This console holds no source data, so when this is off the screens only show "connection guidance".
  • ⓑ AI agent — evolution can run with even one green. If unconnected, use the [Connection wizard].
  • ⓒ Data status — 10 ground truths is the minimum to run evolution. The train : holdout split is automatic and untouchable (exam fairness).
If the evolution loop badge below is not IDLE, a generation is in progress — you can continue on the [Run evolution] screen. Today's run count/cost is measured against the daily limit (Settings).
