Validation data archive

Past signals are reused anytime — view-only · there is no delete button (exclude ≠ delete)

How to use this screen — the permanent store of all validation sessions
Every session made in the validation session console accumulates here. Evolution (evaluate & Evidence) uses this whole archive automatically, so there is no operation to hand-pick sessions (fairness protection).

How to read the table

  • split — automatic train (practice) / holdout (exam) split. Untouchable.
  • Label (method) — only "real-time" counts as research ground truth (retrospective labels are for development).
  • Participating generations — the number of past criteria that have scored this session.

When you click a row

  • The judgment timeline and ground truth side by side — see where the engine went wrong.
  • "Generations that scored this session" — compare how v1.0, gen2, gen3… each read the same session. The engine's improvement across generations shows in one row (demo/document material).
  • [Exclude from research] — remove a mistaken session from evaluation only (reason required, restorable). Not a deletion — signals and labels are preserved permanently.
