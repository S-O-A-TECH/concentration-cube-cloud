과거 신호는 언제든 재활용됩니다 — 조회 전용 · 삭제 버튼은 없습니다 (제외 ≠ 삭제)

이 화면 사용법 — 모든 검증 세션의 영구 보관소
검증 세션 콘솔에서 만든 세션이 전부 여기에 쌓입니다. 진화(evaluate·Evidence)는 이 아카이브 전체를 자동으로 사용하므로, 세션을 골라 넣는 조작은 없습니다(공정성 보호).

표 읽는 법

  • split — train(연습장)/holdout(시험지) 자동 분할. 손댈 수 없습니다.
  • 라벨(방식) — "실시간"만 연구 정답지로 인정됩니다(사후 라벨은 개발용).
  • 참여 세대 — 이 세션을 채점해 본 역대 기준의 수.

행을 클릭하면

  • 판정 타임라인과 정답지가 나란히 — 엔진이 어디서 어긋났는지 눈으로 확인.
  • "이 세션을 채점한 세대들" — 같은 세션을 v1.0, gen2, gen3… 가 각각 어떻게 읽었는지 비교. 엔진이 세대를 거치며 나아지는 과정이 한 줄로 보입니다(데모·문서 소재).
  • [연구 제외] — 실수한 세션을 평가에서만 빼는 것(사유 필수, 복원 가능). 삭제가 아닙니다 — 신호·라벨은 영구 보존.
