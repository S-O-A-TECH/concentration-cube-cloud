Connect AI agent

Select → detect → auth check → (if unauthenticated) terminal login → [Check again] — SPEC-01 wizard

How to use this screen — why and how to connect an agent
An AI agent (Claude Code / Codex) is a tool that reads mistake evidence and produces parameter improvements. This console simply borrows the CLI (subscription account) already logged in on your PC — it does not store any token separately.

Procedure (usually once at first)

  • [Detect + auth check] — checks installation and login status with a real mini call. The first check can take 40s–2min (CLI cold start) — please wait.
  • If "Login required" appears → [Open terminal] — finish logging in (a browser window opens) in the terminal, then [Check again].
  • Once the badge turns green, [Set as default] — this agent is used when running evolution.

Good to know

  • The check result is cached for 30 minutes, and it re-checks automatically right before running evolution.
  • If you connect both, you can pick which to use on the Run evolution screen.
  • Timeout and daily run limit are in Settings.

Run settings

Change timeout and daily limit in Settings. The auth check result is cached for 30 minutes and always re-checked right before running evolution.
