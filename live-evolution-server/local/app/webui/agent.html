AI 에이전트 연결

선택 → 감지 → 인증 확인 → (미인증 시) 터미널 로그인 → [다시 확인] — SPEC-01 마법사

이 화면 사용법 — 에이전트는 왜, 어떻게 연결하나
AI 에이전트(Claude Code / Codex)는 오답 증거를 읽고 파라미터 개선안을 만들어 주는 도구입니다. 이 콘솔은 여러분 PC 에 이미 로그인된 CLI(구독 계정)를 그대로 빌려 씁니다 — 토큰을 따로 저장하지 않습니다.

절차 (보통 최초 1회)

  • [감지 + 인증 확인] — 설치 여부와 로그인 상태를 실제 미니 호출로 확인합니다. 첫 확인은 40초~2분 걸릴 수 있어요 (CLI 콜드 스타트) — 기다려 주세요.
  • "로그인이 필요해요"가 뜨면 → [터미널 열기] — 터미널에서 로그인(브라우저 창이 뜸)을 마친 뒤 [다시 확인].
  • 초록 배지가 되면 [기본으로 지정] — 진화 실행 때 이 에이전트가 쓰입니다.

알아둘 것

  • 확인 결과는 30분 캐시되고, 진화 실행 직전에는 자동으로 다시 확인합니다.
  • 둘 다 연결해 두면 진화 실행 화면에서 골라 쓸 수 있습니다.
  • 타임아웃·일일 실행 상한은 설정에서.

실행 설정

타임아웃·일일 상한은 설정에서 변경합니다. 인증 확인 결과는 30분 캐시되고, 진화 실행 직전에는 항상 재확인합니다.
