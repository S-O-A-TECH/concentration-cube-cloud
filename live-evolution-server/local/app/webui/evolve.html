Run evolution

① Collect evidence → ② AI proposal → ③ Human review → ④ Register candidate → ⑤ Gate exam — adoption only via the human button on the Gate report screen

How to use this screen — where you run one generation of AI proposals

Run conditions

  • Ground truth (real-time labels) 10 or more + operations server (mock) connected + 1 agent connected. If conditions aren't met the run button is disabled and the reason is shown.

What happens at each step

  • COLLECT — gathers 7 kinds of evidence (Mistake Log, feature distributions, etc.) and builds the AI workspace. Holdout is physically excluded.
  • PROPOSE — the agent reads the evidence and, testing itself on a scratchpad (simulate), produces one improvement. Usually 3–8 min — it keeps going even if you leave, and resumes when you return.
  • REVIEW_DIFF — human review turn. Read the change table (what, to what), the diagnosis (why), and the self-test (train before→after), then [Register candidate] or [Discard]. Only submissions that already passed the 4-stage validation (including self-test recomputation cross-check) appear.
  • REGISTERED → EVALUATING — automatic. The operations server re-scores train+holdout and decides the gate.
  • PASSED / REJECTED — if passed, go to [Review gate report →]; if rejected, [Confirm rejection]. A rejection is also kept on record as a lesson for the next generation.

Don't panic if FAILED appears

  • This is the result after automatically attaching feedback and retrying up to 3 times on validation rejection or timeout. Open the raw transcript below (what the agent actually said) to check the cause, then [Clean up] and run again.
