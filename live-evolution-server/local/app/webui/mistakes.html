Mistake Log

10-second bins where ground truth and the judgment disagree in train sessions — the raw form of the evidence the AI agent receives (holdout is not here either)

How to use this screen — a map of "what the engine gets wrong right now"
It compares ground truth (your clicks) against the machine's judgment in 10-second units and shows only the wrong bins.

How to read it

  • Confusion matrix — rows are ground truth, columns are the machine's judgment. The red numbers off the diagonal are mistakes. E.g. "Blank-stare row × Focus column = 12" means "12 bins that were actually blank-stare but misread as focus".
  • Per-state scores — sensitivity (how well it catches that state) and specificity (whether it calls non-cases non-cases). Below 85% is shown in red — that state becomes this evolution's target.
  • Mismatched bin list — a feature summary of each mistake. Use [Timeline ↗] to view that session's bin directly.

Next actions

  • If you see a mistake pattern → [Run evolution from this Mistake Log]. The AI agent receives the same evidence you see here (+ feature distributions) and produces an improvement.
  • If there are almost no mistakes, no evolution is needed — gather more ground truth.
Holdout (hidden exam) sessions are never shown here or to the AI — that's what makes the holdout score on the gate report a real exam.
