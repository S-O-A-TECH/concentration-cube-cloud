실시간 검증 세션 콘솔

[시작]이 기기를 직접 시작시키고, 지시와 동시에 누르는 버튼이 유일한 정답지입니다. 사후 편집은 없습니다 — 실패하면 [연구 제외] 후 5분 세션을 다시 하세요.

이 화면 사용법 — 정답지(라벨)는 여기서만 태어납니다
피검자와 관리자가 같은 공간에 있고, 관리자가 말로 지시하면서 동시에 버튼을 누르는 방식입니다. 버튼 클릭 시각이 곧 정답지가 됩니다 (기기의 세션 시계로 기록 — PC 시계 아님).

준비물

  • 웹캠 프로토가 켜져 있어야 합니다: web_cam_version_prototype 폴더에서 .venv\Scripts\python run.py (기기 배지가 위에 표시됨)
  • 피검자 1명 + 책. 세션은 5분(LAB-5) — 짧게 여러 번이 좋은 데이터를 만듭니다.

진행 (예: 기본5분 프리셋)

  • [시작] → 보정(피검자가 책 네 모서리 응시) → 측정 시작
  • "지금부터 집중해서 읽어!" 라고 말하며 동시에 [집중] 클릭 — 이후 안내판이 다음 지시와 카운트다운을 크게 보여줍니다. 자동 마킹은 없습니다 — 실제로 지시한 순간의 클릭만이 진실.
  • [중단/기타] = 화장실·기침·방해 — 그 구간은 정답지에서 빠집니다(평가 제외).
  • 잘못 눌렀거나 프로토콜이 무너지면 → [폐기하고 다시]. 5분이라 부담이 없습니다.

종료 후

  • 요약을 확인하고 [저장] — 세션당 1회, 수정 불가. 의심스러우면 저장하지 말고 [연구 제외].
  • "동기화 경고" 배지가 있으면 타임라인을 먼저 확인하세요.
  • 저장된 세션은 아카이브 최상단에 나타납니다. 정답지가 10개 이상 모이면 진화 실행이 열립니다.
기기의 실시간 판정은 기본 숨김입니다(피검자가 화면을 볼 수 있고, 관리자 타이밍이 기계에 끌리는 것을 막기 위해) — 필요하면 설정에서 디버그 표시를 켜세요.
