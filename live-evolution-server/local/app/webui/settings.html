How to use this screen — what to change and when
  • Agent run — default agent / timeout / daily limit. The timeout is the total time the agent may spend producing a proposal (including the self-test loop, usually 600–900s).
  • Trigger — when N new ground truths accumulate, the dashboard shows a "proposal ready" notice. Turning on auto-propose mode runs the generation automatically instead of just notifying, but adoption is always the human button on the Gate report screen.
  • Protocol presets — the script for the validation session prompt board. One line = label,seconds,instruction. The board is a reference only; ground truth is always the actual clicks.
  • Session filter — the clinical switchover. Now it's the webcam; in clinical use only the source changes to the research cube (zero code changes).
  • Connection (.env) — for security, server address and token are not edited from the screen. Edit the local/.env file and restart the server.
